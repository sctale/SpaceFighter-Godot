## 1. R1 美术全面对齐

参考作观感拆解：厚黑描边、低分辨率色块、深暗红/深蓝底、金框 UI、粗像素字体、明显的红黄绿青玩具配色。

1. **精灵更块状**：`pixel_neon.py` 降网格（玩家 56→40，敌机 44→32，Boss 96→72），并做 1px 深色描边膨胀；色板提高对比度（纯黑描边 + 高饱和红/金/绿/青）。
2. **背景去雾**：重写 `space_bg.gdshader` 的云层为「阈值硬边云块 + 6 级色阶」，去掉大面积奶油雾；天空主题加深顶部、提高地平线对比；新增程序化像素地形/云带（backdrop `_draw`）增强层次。
3. **像素字体**：引入 OFL 中文像素字体（Fusion Pixel / Ark Pixel），全 UI 使用；失败则回退现有 CJK 并加大描边与投影。
4. **UI 块状化**：圆角 0–2px，金框 + 黑外框双层描边，按钮顶部 3px 高光、底部 4px 硬阴影；标题加粗描边与星徽。
5. **图标**：沿用当前红金像素战机，按新色板重新量化并补黑描边。

## 2. R2 姿态锁定

- `player_bank` 保留变量但绘制恒用 0；引擎火焰、回退图形同样不旋转。
- 敌机绘制角度：普通机恒 0；仅 `rock` 保留自转。
- 僚机/菜单 Hero 机体取消旋转。
- 冲刺/换线只改变位移，不改变朝向。

## 3. R3 护盾环绕

- `main._draw_player` 新增 `_draw_shield_orbit()`：每层护盾绘制一枚青色六边形光球 + 外发光，轨道半径 44px，公共角速度 1.6 rad/s，相位均分。
- 光球绘制在机体之后（可绕到前方），并带 6px 拖尾弧线；护盾破碎时现有边缘青闪保留。
- HUD 三角计数不变。

## 5. R5 十关后分流 + 无尽强度

- 第 10 区 Boss 击破 → 胜利结算，按钮改为「继续无尽」+「返回主菜单」。
- 「继续无尽」：保留分数/升级/残机，`mode="endless"`、`zone=11`、直接进入第 11 区（Boss 0），并写档。
- 无尽强度：`CFG.endless_scale(zone) = pow(1.2, floor((zone-1)/10))`（zone≥11），同时乘到敌机 HP、Boss HP、敌弹速度；界面在星区横幅标注「深度 +20%」。
- 菜单「无尽模式」仍从第 1 区开始，同样在第 11 区起吃到 +20%。
